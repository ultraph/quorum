# QUORUM — режимы «Дуэль» и «Совет»

Дата фиксации: 20.11.2026. Статус: **реализовано** (`council.py` + оркестрация в
`webapp.py`, тесты `test_council.py`). Третий режим рядом с фактчеком
(Research pipeline), который не менялся. Описание для пользователя — блок
«📖 Мануал» вверху веб-страницы.

## Ограничения, под которые сделано

- Grok — **только вручную**: копия промпта → чат Grok → ответ вставляется обратно.
- Gemini — **по подписке Google через `agy`** (Antigravity CLI, OAuth; с 20.11.2026)
  или вручную — переключатель «Подключение Gemini». Через agy доступна только
  Gemini 3.8 Flash; берётся High. `search_web` работает, страницы целиком
  (`read_url_content`) модель не открывает, хотя `read_url(*)` разрешён.
  Запуск: пустой временный каталог, `--sandbox`, свои `--settings` (никаких
  команд, только чтение URL); длинный промпт (>100 КБ) — файлом `task.md`.
  Пустой ответ при коде 0 = модель потянулась к запрещённому инструменту → ошибка.
- Claude и GPT/Codex — автоматически (подписка CLI или API, как в «Подключении»).
- DeepSeek V4 Pro — автоматически по API (центы).
- Qwen и Kimi не участвуют (Kimi исключён договорённостью; Qwen не подключён).
  Агент Nyx не участвует — дублировал бы Claude/Codex.

## ⚔ Дуэль (быстрый)

1. Claude и Codex параллельно пишут свой ответ, не видя друг друга
   (веб — флажок, по умолчанию включён).
2. Судья видит ответы под метками A/B в случайном порядке: **Gemini**
   (по умолчанию с 20.11.2026 — по подписке через agy, или вручную) или
   **DeepSeek** (API). Последняя строка —
   `WINNER: A|B`; вставка Gemini без неё не принимается.
3. Финал пишет **проигравший** автор: основа — победитель + «взять у
   проигравшего» из вердикта судьи.
4. По желанию: Grok-критик (вручную) → кнопка «Учесть критику» — автор финала
   переписывает его, принимая только верные замечания; ссылки критика
   перед этим открывает в вебе (с 20.11.2026).

Ручных вставок 0–2. Время ≈5 мин (замер 20.11.2026: судья DeepSeek ≈2 мин), деньги — подписка + ≈$0.01 DeepSeek.

## 🏛 Совет (полный)

1. Авторы: Claude, Codex, DeepSeek, Gemini через agy (авто, параллельно) +
   Grok вручную (промпт показывается сразу, пока авто-авторы работают). Ручного
   автора можно пропустить. Gemini «вручную» — тоже ручной автор.
2. Слепая взаимная оценка: оценивают **только авто-модели** (Claude, Codex,
   DeepSeek); каждый видит ответы под буквами и **без своего**. Ответ
   заканчивается строками `RANKING: X > Y > …` и `SCORES: X=n, …`.
   Нераспознанная оценка не учитывается; нужно минимум две.
3. Агрегация — Borda, нормированная на 0..1 в каждом ранжировании (у ответов
   разное число оценок), среднее; ничья → средний балл → число первых мест.
4. Финал пишет **Claude**; если победил ответ Claude — **Codex** (решение
   20.11.2026: по прежнему правилу «лучшая по рейтингу авто-модель» финал
   достался DeepSeek, который вернул необоснованные проценты и выкинул источники).
5. По желанию: Grok-критик + «Учесть критику» — как в дуэли.

Ручных вставок 2–3. Время ≈3–5 мин + вставки (замер 20.11.2026), деньги — подписка +
≈$0.02–0.05 DeepSeek.

## Как устроено

- Прогон — возобновляемая машина состояний: готовые шаги лежат в
  `run["results"]`, буквы — в `run["labels"]` (для воспроизводимости).
  Шаг, ждущий ручной вставки, паркует прогон со статусом `waiting`
  (⏸ в истории); `POST /api/runs/{id}/manual` принимает
  `{key, text}` / `{key, skip}` / `{key: "apply", go}` / `{retry}` и
  продолжает с того же места. Упавший шаг повторяется один («↻ Продолжить»),
  готовые не пересчитываются.
- Запуск — `POST /api/council` `{mode, question, attachments, judge, web}`,
  поток событий — тот же `/api/runs/{id}/stream`. Новые события: `manual`
  (что вставить), `skipped`, `ranking`.
- Беседа после финала работает и здесь (`COUNCIL_CHAT`): в ней авторы раскрыты.
- Стоимость — общий счётчик темы; DeepSeek V4 Pro считается по peak-цене
  ($1.32 / $3.96 за 1M in/out — верхняя оценка).
