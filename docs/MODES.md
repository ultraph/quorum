# QUORUM — режимы «слепой» генерации и оценки (план)

Дата фиксации: 20.11.2026. Статус: идея, код не менялся.

## A. Быстрый режим (fast duel)

1. Claude и ChatGPT пишут каждый свою версию, не видя друг друга (параллельно).
2. Gemini получает обе версии вслепую (метки A/B, порядок случайный) и выбирает победителя с обоснованием.
3. Агент (Nyx) пишет финальную версию на основе победителя, добавляя сильные места из версии второго места.

Шаги: 2 генерации → 1 судейство → 1 синтез.

## B. Полный режим (full panel)

1. Claude, ChatGPT, Gemini, Qwen, Kimi, Grok пишут каждый свой ответ; агент тоже пишет свой.
2. Все 7 ответов анонимизируются (метки, случайный порядок).
3. Каждый участник оценивает работы остальных, свою не оценивает никогда.
4. Агрегация оценок (средний балл/ранг по каждому ответу) → итог.

Шаги: 7 генераций → 7 оценок (каждая на 6 чужих ответов) → агрегация.

## Правила для обоих режимов

- Слепота: модели не знают авторов ответов (только метки).
- Самооценка запрещена: ответ автора исключается из его оценочного набора.
- Порядок ответов рандомизируется на каждом запуске; фиксируется в логе запуска для воспроизводимости.
- Оценка — по заранее заданным критериям (правильность, полнота, ясность, соответствие задаче), балл + короткое обоснование.

## Что нужно в quorum.py (gap analysis)

- Провайдеры: есть anthropic, openai, xai (Grok), gemini, deepseek.
  Нет: Qwen, Kimi → нужен новый провайдер (вероятно openai-compatible base_url) — проверить API-доступ.
- Агент (Nyx) в роли участника: не провайдер, а отдельный шаг — вход в набор ответов и в список оценщиков; оценивает чужие, но не свой.
- Новый оркестратор: фазы generate → anonymize → judge → aggregate (сейчас есть только judge-синтез).
- Флаг режима: `--mode fast|full` (для веб-UI — переключатель).

## Открытые вопросы

- Кто агрегирует в full-режиме: среднее баллов или Borda/ранжирование?
- Оценивает ли агент (Nyx) как судья в full-режиме, или только участвует как автор?
- Бюджет: full-режим = 7 генераций + 7 оценок, ориентир по стоимости до запуска.
